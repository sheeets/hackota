### Nvidia

1. Baseline system at default settings to know your starting, record values for comparison after making changes to overclocking parameters.
  - Speed Way
  - Port Royal
  - Steel Nomad (Primary)
2. Set GPU power to 100% and re-run benchmarking, record values.
3. Increment GPU Voltage in 20% increments, record values.
  - Tick `Unlock voltage control` in MSI Afterburner settings.

#### Tools
- MSI Afterburner
- 3DMark
